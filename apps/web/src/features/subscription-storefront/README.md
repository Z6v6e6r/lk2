# Subscription storefront UI

Переиспользуемый визуальный каркас витрин абонементов. Он не загружает каталог, не создаёт
заказы и не вызывает платёжные или Viva API.

## Граница работы дизайнера

Сотрудник может менять:

- `SubscriptionStorefront.tsx`;
- `SubscriptionOfferSection.tsx`;
- `SubscriptionPlanCard.tsx`;
- `subscriptions.css`;
- ассеты внутри `assets/`.

Контракт `model.ts`, preview-каталоги, `main.tsx`, API gateway и серверные пакеты остаются за
границей визуальной задачи. Изменение контракта согласовывается отдельно.

## Локальный preview

Запуск из корня worktree:

```bash
npm run dev:web -- --host 127.0.0.1
```

Сценарии:

- `/__preview/subscriptions` — три карточки из исходного desktop-макета;
- `/__preview/subscriptions?scenario=ab-leto` — конфигурация страницы типа `ab_leto`;
- `/__preview/subscriptions?scenario=multi` — несколько секций для вертикального скролла.

Preview доступен только в Vite DEV. Кнопка выбора обновляет локальное уведомление и не выполняет
покупку.

## Адаптивный контракт

- до `719px`: вертикальный скролл страницы, внутри секции горизонтальная snap-лента;
- от `720px`: сетка из трёх карточек, дополнительные карточки переносятся на новую строку;
- у страницы не должно быть горизонтального overflow;
- rail и интерактивные элементы должны оставаться доступными с клавиатуры.
