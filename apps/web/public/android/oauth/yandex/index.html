Если приложение не открылось

  1. В настройках Android откройте «Приложения → ПадлхАБ → Открывать по умолчанию» и разрешите открытие поддерживаемых ссылок.
  2. Отключите VPN или прокси и начните вход заново.
  3. Обновите приложение до последней версии.
  4. Если вход через Яндекс ID не завершается, вернитесь в приложение и войдите по СМС.
