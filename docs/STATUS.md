## Что включено на тестовом стенде

Включено: игры (чтение и команды), два тестовых корта, история активности, блокировка в чатах,
realtime сообществ, полный клиентский доступ для беты.

Выключено (`deploy/test-stand/stand.env.example`): коммерческие CREATE/JOIN игр, реестр правил
подписок, покупка месячной подписки, вход через Viva OAuth, web push, медиа в чатах и сообществах,
подарочные сертификаты. Возвраты Viva (CURRENCY/DEPOSIT) и возврат посещения тренировки в первой
версии выключены, возвраты — вручную.

## Мобильное приложение

Android CI собирает только неподписанный release-APK — на телефон его не поставить. Подпись —
черновик PR #567; сторы отложены владельцем. Для демо нужна либо подпись, либо отладочная сборка,
смотрящая на `test.lk2.padlhub.su` (адрес уже есть в `apps/mobile/src/runtime-config.ts`).
Черновик PR #609 убирает верхние панели навигации Android. iOS — после Android.

## Ждёт владельца

- SHA для первого запуска беты на lk2.padlhub.su и одобрение `promote`.
- Решение по демо-APK: подпись (PR #567) или отладочная сборка.
- Тестовые аккаунты для беты с правом `games.test-courts`.
- Проверка действующей привязки месячной подписки в Node-RED ЛК1 (только чтение).
