# R1 — APK для самостоятельного тестирования

Тестовая сборка **1.13 (14)**, Android7.0+. Файл: `PadlHub-R1-test-1.13-de451e71.apk` (27,050,008bytes). Source `de451e712c08aae46fdc47ae162c20ce038657bd`; SHA256 `5cfa69dba0a1b86914467208756b6cdae5652bd03a20336362416cea63197dba`.

## Установка

1. Скачайте APK на телефон и откройте файл.
2. При запросе Android разрешите установку из используемого браузера или файлового менеджера.
3. Если PadlHub уже установлен, выберите обновление. При ошибке подписи сохраните текст ошибки; удалять прежнее приложение и его данные пока не нужно.
4. Откройте PadlHub, войдите и разрешите уведомления для проверки push.

Используется существующая debug-подпись; новые ключи не создавались. Это тестовый APK, не публикация Google Play. Package `ru.padlhub.app`; API `https://lk2.padlhub.su`; tenant `local-padel`. Владелец устанавливает самостоятельно; USB и доступ агента к телефону не требуются.

## Состояние сервера

**Полная функциональная приёмка ещё не готова.** R5 enrollment завершён; приложения пока702/871, БД106. Новые R1 write paths требуют migrations119, проверки реальных ролей, безопасного обновления четырёх компонентов и разрешённой активации. Успешный health/readiness не заменяет эти проверки. CUP queue custody, monthly binding, attributable Viva refund/visit-return и фактическая доставка push остаются отдельными незакрытыми условиями. APK не скрывает эти ограничения и не заменяет серверную активацию.
