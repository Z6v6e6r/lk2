# ЛК2 — статус первой версии

Обновлено: 2026-11-08. Единственная страница статуса в режиме первой версии (AGENTS.md, «First-version mode»).
История и доказательства R1 — в `docs/release/R1-*.md`; новые контрольные точки туда не добавляются.

**Коротко:** lk2.padlhub.su — основной контур тестирования, на нём последний серверный код; тестовый
стенд решено выключить. Для Android есть release-APK, подписанный ключом владельца.

## Что включено на тестовом стенде

Включено: игры (чтение и команды), два тестовых корта, история активности, блокировка в чатах,
realtime сообществ, полный клиентский доступ для беты.

Выключено (`deploy/test-stand/stand.env.example`): коммерческие CREATE/JOIN игр, реестр правил
подписок, покупка месячной подписки, вход через Viva OAuth, web push, медиа в чатах и сообществах,
подарочные сертификаты. Возвраты Viva (CURRENCY/DEPOSIT) и возврат посещения тренировки в первой
версии выключены, возвраты — вручную.

## Мобильное приложение

Android CI собирает только неподписанный release-APK. Для тестов есть release-APK 1.13 (14) из main
`7a16312d`, собранный локально вне Git для `https://lk2.padlhub.su` (тенант `local-padel`, Firebase
`padlhub`) и подписанный upload-ключом владельца (сертификат SHA-256 `8C:59:A9:…:70:1E`, см.
`docs/runbooks/android-development.md`). Поверх debug-сборок он не ставится: старую сборку нужно
удалить. App Links и вход через Яндекс для него требуют этого отпечатка в `assetlinks.json` на lk2.
Офлайн-сборка AAB для стора — черновик PR #567; сторы отложены владельцем. iOS — после Android.
